# Guia de contribucion

## Ramas

No trabajes directo sobre `main`, `master` ni `dev`.

## Commits profesionales

- `feat(node): resolver ejercicio 01`
- `feat(express): agregar ruta health`
- `fix(api): validar body requerido`
- `docs(entrega): explicar endpoints`
- `test(service): agregar caso de error`
- `refactor(routes): separar controlador`

## Entrega

Solo dentro de:

```text
nivel/ejercicio-XX/resoluciones/nombre-apellido/
```
