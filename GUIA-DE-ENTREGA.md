# Guia de entrega

## Regla principal

Cada solucion debe ir dentro de una carpeta personal:

```text
basico/ejercicio-01/resoluciones/nombre-apellido/
intermedio/ejercicio-01/resoluciones/nombre-apellido/
avanzado/ejercicio-01/resoluciones/nombre-apellido/
```

## No permitido

- PR hacia `main`.
- Subir `node_modules/`.
- Subir `.env` con secretos.
- Modificar README base del ejercicio.
- Borrar entregas de otros estudiantes.
