# Ejercicio 28: Colección de ejemplos HTTP

## Propósito

Entregar peticiones reproducibles para explorar una API de battle royale. El archivo `requests.http` incluye ejemplos de consulta y creación que pueden ejecutarse desde una extensión de cliente HTTP compatible con VS Code.

## Ejecución

Requiere Node.js 20 o superior. Ejecuta `npm install` y `npm run dev`. Abre `requests.http` y envía las solicitudes en orden cuando quieras observar cómo cambia la colección en memoria.

## Recursos

- `GET /api/squads`: lista escuadrones.
- `POST /api/squads`: crea un escuadrón indicando su nombre.
