# Ejercicio 19: dotenv y configuración

## Propósito

Centralizar la configuración de un estudio de tatuajes y cargarla desde variables de entorno con `dotenv`. El puerto y el nombre del estudio no quedan dispersos en las rutas.

## Ejecución y prueba

Requiere Node.js 20 o superior. Copia `.env.example` como `.env`, ejecuta `npm install` y `npm run dev`. Consulta `GET /api/studio` para ver la configuración activa. No guardes secretos reales en el repositorio.
