# Ejercicio 09: Paginación y filtros

## Propósito

Consultar una lista de deportistas de kickboxing con filtro opcional por categoría y paginación. La respuesta informa los resultados, la página actual y el total de coincidencias.

## Ejecución y prueba

Requiere Node.js 20 o superior. Ejecuta `npm install` y `npm run dev`. Prueba `GET /api/fighters?page=1&limit=2&category=ligero`. `page` y `limit` deben ser enteros positivos.
