# Ejercicio 10: ordenamiento de resultados

## Propósito
Presentar jugadores de pingpong ordenados desde el mayor número de victorias al menor.

## Ejecución y resultado esperado
Ejecuta `npm install` y `npm start`. Consulta `GET http://localhost:3000/players`:
```json
[
  { "name": "Mia", "wins": 7 },
  { "name": "Kai", "wins": 4 },
  { "name": "Ian", "wins": 2 }
]
```
La lista original no se altera al ordenar los resultados.
