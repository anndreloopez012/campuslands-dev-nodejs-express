# Ejercicio 23: testing con node:test

## Propósito
Calcular el área de una soldadura multiplicando su ancho por su largo. Las pruebas automáticas verifican el cálculo y el rechazo de medidas no positivas.

## Ejecución y resultados esperados
Ejecuta `npm install` y `npm test`; ambas pruebas deben aprobarse. Luego inicia la API con `npm start` y consulta `GET /weld/2/5`:
```json
{ "area": 10 }
```
