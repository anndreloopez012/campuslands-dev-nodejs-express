# Ejercicio 04: servicios reutilizables

## Propósito
Calcular los puntos de una partida battle royale mediante una función de servicio reutilizable.

## Ejecución y resultado esperado
Ejecuta `npm install` y `npm start`. Consulta `GET http://localhost:3000/match`:
```json
{ "total": 18 }
```
El ejemplo suma dos puntos por cada una de las cuatro eliminaciones y diez puntos por la posición.
