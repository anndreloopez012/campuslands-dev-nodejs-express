# Ejercicio 11: Búsqueda textual

## Propósito

Buscar canciones por título o artista sin distinguir mayúsculas de minúsculas. El parámetro de consulta se limpia antes de comparar con los datos de ejemplo.

## Ejecución y prueba

Requiere Node.js 20 o superior. Ejecuta `npm install` y `npm run dev`. Prueba `GET /api/songs?q=luna`; una búsqueda sin coincidencias devuelve una lista vacía.
