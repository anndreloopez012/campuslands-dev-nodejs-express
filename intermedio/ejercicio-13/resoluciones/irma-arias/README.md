# Ejercicio 13: Relaciones simples

## Propósito

Relacionar tripulantes con naves de ciencia ficción mediante `shipId`. La consulta de una nave permite obtener únicamente los tripulantes asociados a ella.

## Ejecución y prueba

Requiere Node.js 20 o superior. Ejecuta `npm install` y `npm run dev`. Prueba `GET /api/ships/1/crew`; si la nave no existe, la API responde `404`.
