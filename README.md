# Campuslands Dev Node.js Express

Repositorio publico de ejercicios de Node.js y Express para estudiantes de Campuslands.

## Proposito educativo

Aprender backend con Node.js desde cero hasta un nivel avanzado controlado, practicando con ejercicios utiles, progresivos y enfocados en proyectos reales.

## Niveles incluidos

- [Basico](./basico): 30 ejercicios.
- [Intermedio](./intermedio): 30 ejercicios.
- [Avanzado](./avanzado): 30 ejercicios.

## Ramas principales

- `main`: produccion. No recibe entregas estudiantiles.
- `dev`: integracion. Todos los Pull Requests de estudiantes deben apuntar aqui.

## Flujo rapido

```bash
git clone https://github.com/anndreloopez012/campuslands-dev-nodejs-express.git
cd campuslands-dev-nodejs-express
git switch dev
git pull origin dev
git switch -c alumno/nombre-apellido/ejercicio-01
```

Entrega solo dentro de `resoluciones/nombre-apellido/` y abre PR hacia `dev`.
