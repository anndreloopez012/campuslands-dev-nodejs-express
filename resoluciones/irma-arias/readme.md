##  Descripción del Problema
Este proyecto implementa una solución backend inicial utilizando **Node.js** y **Express**, estructurada de manera modular y profesional por capas (rutas, controladores y servicios). El objetivo principal es dominar los conceptos básicos del entorno de ejecución de Node, el manejo de rutas y la respuesta estructurada de APIs orientadas a un escenario de videojuegos RPG.
