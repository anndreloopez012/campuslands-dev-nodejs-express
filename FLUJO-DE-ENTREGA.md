# Flujo de entrega

1. Haz fork.
2. Clona tu fork.
3. Cambia a `dev`.
4. Crea rama personal.
5. Trabaja en `resoluciones/nombre-apellido/`.
6. Haz commit profesional.
7. Sube la rama.
8. Abre PR hacia `dev`.

```bash
git switch dev
git pull origin dev
git switch -c alumno/nombre-apellido/ejercicio-01
git add .
git commit -m "feat(node): resolver ejercicio 01"
git push origin alumno/nombre-apellido/ejercicio-01
```
