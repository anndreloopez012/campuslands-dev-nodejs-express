# Ejercicio 01: diseño de API versionada

## Propósito
Separar la primera versión de una API RPG bajo la ruta `/api/v1`.

## Ejecución y resultado
Ejecuta `npm install` y `npm start`, luego consulta `GET /api/v1/heroes`:
```json
[{ "name": "Ayla", "class": "mage" }]
```
La versión en la dirección permite identificar qué contrato de API se está usando.
