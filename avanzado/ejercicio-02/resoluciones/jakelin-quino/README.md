# Ejercicio 02: arquitectura escalable

## Propósito
Organizar una API de jugadores de shooter en rutas, controladores y servicios.

## Ejecución y resultado
Ejecuta `npm install` y `npm start`. `GET /players` responde:
```json
[{ "name": "Nova", "rank": "Gold" }]
```
Cada parte tiene una responsabilidad clara y puede ampliarse por separado.
