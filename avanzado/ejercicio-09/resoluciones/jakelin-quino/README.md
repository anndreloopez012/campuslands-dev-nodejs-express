# Ejercicio 09: streams básicos

## Propósito
Enviar como flujo un resumen de sesiones de entrenamiento de kickboxing.

## Ejecución y resultado
Ejecuta `npm install` y `npm start`, luego consulta `GET /sessions.txt`. La respuesta es texto enviado por partes:
```text
Sesiones de entrenamiento
Lunes: técnica
Miércoles: resistencia
```
El encabezado de respuesta indica que el contenido es texto plano.
