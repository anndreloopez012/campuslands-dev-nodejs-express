# Ejercicio 13: observabilidad y logs

## Propósito
Registrar en consola información básica de cada petición a la API de ciencia ficción.

## Ejecución y resultado
Ejecuta `npm install` y `npm start`, luego consulta `GET /ships`:
```json
[{ "name": "Orion", "destination": "Europa" }]
```
En la consola también aparecerán el método, la ruta, el estado HTTP y la duración de la petición.
