# Instrucciones generales

Este repositorio se trabaja paso a paso. No saltes ejercicios si aun no puedes explicar el anterior.

## Recomendacion

- Basico: entiende Node, npm, modulos, rutas y respuestas.
- Intermedio: aprende capas, middleware, validaciones, auth y tests.
- Avanzado: practica arquitectura, seguridad, observabilidad, jobs e integracion.
