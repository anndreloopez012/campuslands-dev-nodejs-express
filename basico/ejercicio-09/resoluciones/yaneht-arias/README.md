# Ejercicio 09 - JSON y persistencia simple

Solución sencilla con Node.js y JavaScript, sin Express ni dependencias externas.

## Comandos

Desde la raíz del repositorio, usa cualquiera de estos comandos:

- `cd basico/ejercicio-09/resoluciones/yaneht-arias && npm start`

## Resultado en consola

```text
=== Ejercicio 09: JSON ===
Datos: { jugador: 'Nova', puntos: 120 }
Guardado: {"jugador":"Nova","puntos":120,"nivel":2}
```
