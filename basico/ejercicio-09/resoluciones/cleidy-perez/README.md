# Ejercicio 09 - JSON y persistencia simple

Solución sin dependencias externas para practicar **JSON y persistencia simple** en el contexto de kickboxing.

## Ejecutar

```bash
cd basico/ejercicio-09/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
