# API de Kickboxing - JSON y Persistencia Simple

## Autor

Wilder Catú

## Descripción

Este proyecto es una pequeña solución backend desarrollada con Node.js
para practicar el uso de JSON y persistencia simple.

La temática utilizada es el kickboxing.

La aplicación implementa una API HTTP que permite consultar, crear y
actualizar información de kickboxers.

Los datos se almacenan en un archivo:

```text
kickboxers.json
