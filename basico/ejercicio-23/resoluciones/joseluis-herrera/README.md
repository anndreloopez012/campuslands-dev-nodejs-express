# Ejercicio 23 - Datos en memoria

## Temática

Soldadura.

## Objetivo

Crear una API sencilla con Node.js y Express para practicar el uso de **datos en memoria**.

Los trabajos de soldadura se almacenan temporalmente en un array de JavaScript.

El ejercicio también mantiene la separación entre:

* Routes
* Controllers
* Services

---

## Tecnologías

* Node.js
* Express
* JavaScript
* JSON
* API REST
