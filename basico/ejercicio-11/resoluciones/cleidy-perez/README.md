# Ejercicio 11 - promesas basicas

Solución sin dependencias externas para practicar **promesas basicas** en el contexto de musica.

## Ejecutar

```bash
cd basico/ejercicio-11/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
