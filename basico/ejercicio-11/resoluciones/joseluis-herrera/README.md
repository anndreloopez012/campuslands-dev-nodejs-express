# Ejercicio 11 - API de Música

## Temática

Música.

## Objetivo

Crear una pequeña API REST utilizando **Node.js** y **Express** para practicar el uso de **Promesas básicas**.

El ejercicio simula la obtención de canciones mediante una operación asíncrona.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* Promesas
* Async/Await
