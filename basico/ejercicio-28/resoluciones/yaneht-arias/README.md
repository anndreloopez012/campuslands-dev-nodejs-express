# Ejercicio 28 - configuración por entorno

Solución sencilla con Node.js y JavaScript, sin Express ni dependencias externas.

## Comandos

Desde la raíz del repositorio, usa cualquiera de estos comandos:

- `cd basico/ejercicio-28/resoluciones/yaneht-arias && npm start`
- `cd basico/ejercicio-28/resoluciones/yaneht-arias && PORT=4000 npm start`
