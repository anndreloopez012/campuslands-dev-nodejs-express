# Ejercicio 28 - configuracion por entorno

Solución sin dependencias externas para practicar **configuracion por entorno** en el contexto de battle royale.

## Ejecutar

```bash
cd basico/ejercicio-28/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
