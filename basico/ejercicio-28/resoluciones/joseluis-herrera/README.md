# Ejercicio 28 — Configuración por entorno

## Temática

Battle Royale.

## Objetivo

Crear una API sencilla con Node.js y Express que utilice **variables de entorno** para controlar la configuración de la aplicación.

El ejercicio introduce el uso de `.env`, `process.env` y `dotenv`.

---

## Tecnologías

* Node.js
* Express
* dotenv
* JavaScript
* Variables de entorno
* HTTP
