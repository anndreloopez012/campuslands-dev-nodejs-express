# Ejercicio 12 - API de Películas de Miedo

## Temática

Películas de miedo.

## Objetivo

Crear una pequeña API REST utilizando **Node.js** y **Express** para practicar el uso de `async/await`.

El ejercicio simula la obtención de películas mediante una operación asíncrona.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* Promesas
* Async/Await
