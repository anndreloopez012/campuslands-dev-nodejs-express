# Basico 12 - async await

Tematica: peliculas de miedo

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

El servidor corre en http://localhost:3000

## Probar

```bash
curl http://localhost:3000/basico/ejercicio-12
curl http://localhost:3000/basico/ejercicio-12/peliculas
curl http://localhost:3000/basico/ejercicio-12/peliculas/2
curl http://localhost:3000/basico/ejercicio-12/peliculas/99
curl http://localhost:3000/basico/ejercicio-12/resumen
```
