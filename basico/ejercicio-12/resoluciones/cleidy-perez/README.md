# Ejercicio 12 - async await

Solución sin dependencias externas para practicar **async await** en el contexto de peliculas de miedo.

## Ejecutar

```bash
cd basico/ejercicio-12/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
