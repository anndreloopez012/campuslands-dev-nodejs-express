# API de Hiperdeportivos - Variables de Entorno

## Autor

Wilder Catú

## Descripción

Este proyecto es una pequeña solución backend desarrollada con Node.js
para practicar el uso de variables de entorno.

La temática utilizada es un catálogo de hiperdeportivos.

El objetivo principal es comprender cómo una aplicación backend puede
recibir configuración externa mediante `process.env`, evitando colocar
directamente ciertos valores de configuración dentro del código fuente.

El proyecto utiliza únicamente módulos nativos de Node.js y no requiere
dependencias externas.

---

# Objetivo

Practicar los siguientes conceptos:

- Node.js
- Variables de entorno
- `process.env`
- Configuración de un servidor
- API HTTP
- Rutas
- Validación básica
- Códigos de estado HTTP
- Manejo de errores
- Separación de responsabilidades
- Documentación de una API
