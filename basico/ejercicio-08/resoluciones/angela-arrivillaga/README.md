# Basico 08 - variables de entorno

Tematica: hiperdeportivos

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

El servidor corre en http://localhost:3000

## Probar

```bash
curl http://localhost:3000/basico/ejercicio-08
curl http://localhost:3000/basico/ejercicio-08/config
curl http://localhost:3000/basico/ejercicio-08/autos/1
curl http://localhost:3000/basico/ejercicio-08/autos/99
```

## Variables de entorno

El archivo `.env.example` tiene los valores de ejemplo. Para usarlo:

```bash
npm run start:env
```

En ese caso el servidor corre en el puerto 4000.
