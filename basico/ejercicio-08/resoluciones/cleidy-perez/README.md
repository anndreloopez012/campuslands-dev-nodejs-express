# Ejercicio 08 - variables de entorno

Solución sin dependencias externas para practicar **variables de entorno** en el contexto de hiperdeportivos.

## Ejecutar

```bash
cd basico/ejercicio-08/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
