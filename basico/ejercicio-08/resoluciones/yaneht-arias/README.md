# Ejercicio 08 - variables de entorno

Solución sencilla con Node.js y JavaScript, sin Express ni dependencias externas.

## Comandos

Desde la raíz del repositorio, usa cualquiera de estos comandos:

- `cd basico/ejercicio-08/resoluciones/yaneht-arias && npm start`
- `cd basico/ejercicio-08/resoluciones/yaneht-arias && PLAYER_NAME=Explorador GAME_MODE=duo npm start`
