# Ejercicio 18 - rutas POST

Solución sin dependencias externas para practicar **rutas POST** en el contexto de paracaidismo.

## Ejecutar

```bash
cd basico/ejercicio-18/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
