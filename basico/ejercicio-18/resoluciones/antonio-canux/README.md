# Ejercicio 18 - Rutas POST (Paracaidismo)

**Alumno:** Antonio Canux  
**Tema:** Rutas POST en Express  
**Temática:** Paracaidismo  
**Ruta:** `/basico/ejercicio-18`

## Ejecución
```bash
npm install
npm run dev
```

## Endpoints
- `GET /basico/ejercicio-18` - Estado del ejercicio.
- `GET /basico/ejercicio-18/saltos` - Listar registros de saltos.
- `POST /basico/ejercicio-18/saltos` - Registrar nuevo salto en paracaídas.
