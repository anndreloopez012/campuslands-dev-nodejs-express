# Ejercicio 18 - Paracaidismo

## Descripción

En este ejercicio se crea una pequeña API REST utilizando Node.js y Express para practicar el uso de rutas POST.

La temática utilizada es paracaidismo.

La API permite consultar los saltos registrados y registrar nuevos saltos mediante una petición POST.

El objetivo principal es comprender cómo una API recibe información enviada por el cliente, valida los datos y crea un nuevo recurso.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* npm
* Postman
