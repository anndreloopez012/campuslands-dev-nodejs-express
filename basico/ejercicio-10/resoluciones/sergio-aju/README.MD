# BASICO 10 - Funciones asíncronas

## Descripción

Ejercicio básico para aprender a utilizar funciones asíncronas en Node.js.

Se simula un partido de ping-pong utilizando `async`, `await` y `Promise`.

## Ejecutar

```bash
npm start
```

## Resultado

```text
Preparando partido...
El partido terminó.
Resultado: 11 - 8
```

## Conceptos utilizados

* `async`
* `await`
* `Promise`
* `setTimeout`
