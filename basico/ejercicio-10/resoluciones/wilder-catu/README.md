# API de Ping Pong - Funciones Asíncronas

## Autor

Wilder Catú

## Descripción

Este proyecto es una pequeña solución backend desarrollada con Node.js
para practicar el uso de funciones asíncronas.

La temática utilizada es el ping pong.

La aplicación implementa una API HTTP que permite consultar, crear y
actualizar jugadores.

El objetivo principal es comprender cómo utilizar:

- `async`
- `await`
- Promises
- `try/catch`
- `fs/promises`

para trabajar con operaciones que pueden tardar en completarse.

---

# Objetivo

Practicar los siguientes conceptos:

- Node.js
- Funciones asíncronas
- `async`
- `await`
- Promises
- `try/catch`
- Operaciones asíncronas con archivos
- API HTTP
- Rutas
- Métodos GET, POST y PUT
- Validación básica
- Códigos de estado HTTP
- Manejo de errores
