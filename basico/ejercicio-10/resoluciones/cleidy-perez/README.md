# Ejercicio 10 - funciones asincronas

Solución sin dependencias externas para practicar **funciones asincronas** en el contexto de pingpong.

## Ejecutar

```bash
cd basico/ejercicio-10/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
