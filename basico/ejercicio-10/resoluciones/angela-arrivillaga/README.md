# Basico 10 - funciones asincronas

Tematica: pingpong

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

El servidor corre en http://localhost:3000

## Probar

```bash
curl http://localhost:3000/basico/ejercicio-10
curl http://localhost:3000/basico/ejercicio-10/jugadores
curl http://localhost:3000/basico/ejercicio-10/partidos/1
curl http://localhost:3000/basico/ejercicio-10/partidos/99
curl http://localhost:3000/basico/ejercicio-10/resumen
```
