# Ejercicio 10 - funciones asincronas

Practica de funciones `async` y operaciones asincronas usando solo Node.JS.

## Uso

Ubicarse en:
```bash
basico/ejercicio-10/resoluciones/jakelin-quino/
```

El programa espera una operacion asincrona y luego lee el resultado de un partido de pingpong desde `data/match.json`. Probar:
```bash
npm start
```
Resultado:
```bash
Mateo 21 - 18 Julian
```
