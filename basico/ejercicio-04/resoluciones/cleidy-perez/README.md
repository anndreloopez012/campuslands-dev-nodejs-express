# Ejercicio 04 - modulos ES Modules

Solución sin dependencias externas para practicar **modulos ES Modules** en el contexto de battle royale.

## Ejecutar

```bash
cd basico/ejercicio-04/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
