# Ejercicio 04 - modulos ES Modules

Practica de modulos ES Modules usando solo Node.JS.

## Uso

Ubicarse en:
```bash
basico/ejercicio-04/resoluciones/jakelin-quino/
```

El proyecto usa `import` y `export` entre `src/index.js` y `src/squad.js`. La propiedad `type` del `package.json` activa ES Modules para Node.js. Probar:
```bash
npm start
```
Resultado:
```bash
Zona Final aterriza en Torres del norte con 4 jugadores.
Escuadron: Astra, Bolt, Ciro, Duna
```
