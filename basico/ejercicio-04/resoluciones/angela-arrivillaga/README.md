# Basico 04 - modulos ES Modules

Tematica: battle royale

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

El servidor corre en http://localhost:3000

## Probar

```bash
curl http://localhost:3000/basico/ejercicio-04
curl http://localhost:3000/basico/ejercicio-04/jugadores
curl "http://localhost:3000/basico/ejercicio-04/puntaje?kills=5&posicion=3"
curl "http://localhost:3000/basico/ejercicio-04/puntaje?kills=5&posicion=500"
```
