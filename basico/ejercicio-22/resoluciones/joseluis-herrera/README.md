# Ejercicio 22 - Services en Node.js y Express

## Temática

Arquitectura 3D.

## Objetivo

Crear una API sencilla con Node.js y Express para practicar la separación de responsabilidades utilizando:

* Routes
* Controllers
* Services

El ejercicio permite consultar, buscar y registrar proyectos de arquitectura 3D.

---

## Tecnologías

* Node.js
* Express
* JavaScript
* API REST
* JSON
