# Ejercicio 22 - servicios simples

Solución sin dependencias externas para practicar **servicios simples** en el contexto de arquitectura 3D.

## Ejecutar

```bash
cd basico/ejercicio-22/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
