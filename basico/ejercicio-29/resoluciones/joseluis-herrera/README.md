# Ejercicio 29 — API de fútbol y fútbol sala

## Descripción

API sencilla desarrollada con **Node.js y Express** para consultar información básica de equipos de fútbol y fútbol sala.

El objetivo principal de este ejercicio es practicar la creación de un **README técnico**, documentando de forma clara cómo instalar, ejecutar y probar una API.

---

## Tecnologías

* Node.js
* Express
* JavaScript
* HTTP
* JSON

---

## Requisitos

Antes de ejecutar el proyecto necesitas tener instalado:

* Node.js
* npm

Puedes comprobar las versiones con:

```bash
node --version
npm --version
```
