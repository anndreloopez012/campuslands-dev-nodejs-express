# Ejercicio 13 - manejo de errores

Solución sin dependencias externas para practicar **manejo de errores** en el contexto de ciencia ficcion.

## Ejecutar

```bash
cd basico/ejercicio-13/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
