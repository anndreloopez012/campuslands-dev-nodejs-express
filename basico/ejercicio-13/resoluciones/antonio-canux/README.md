# Ejercicio 13 - Manejo de Errores (Ciencia Ficción)

**Alumno:** Antonio Canux  
**Tema:** Manejo de errores en Express  
**Temática:** Ciencia Ficción  
**Ruta:** `/basico/ejercicio-13`

## Ejecución
```bash
npm install
npm run dev
```

## Endpoints
- `GET /basico/ejercicio-13` - Estado del ejercicio.
- `GET /basico/ejercicio-13/artifacts` - Listar artefactos sci-fi.
- `GET /basico/ejercicio-13/artifacts/:id` - Obtener artefacto o error 404/400.
- `POST /basico/ejercicio-13/artifacts` - Crear artefacto con validación y manejo de errores.
