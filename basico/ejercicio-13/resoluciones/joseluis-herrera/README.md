# Ejercicio 13 - API de Ciencia Ficción

## Temática

Ciencia ficción.

## Objetivo

Crear una pequeña API REST utilizando **Node.js** y **Express** para practicar el **manejo de errores**.

La API permite consultar una lista de personajes de ciencia ficción y buscar un personaje específico mediante su ID.

El ejercicio también demuestra cómo validar los datos recibidos y cómo devolver diferentes códigos HTTP cuando ocurre un error.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* HTTP
* Manejo de errores
* Validación básica
