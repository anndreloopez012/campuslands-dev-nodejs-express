# Ejercicio 17 - rutas GET

Solución sin dependencias externas para practicar **rutas GET** en el contexto de viajes y turismo.

## Ejecutar

```bash
cd basico/ejercicio-17/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
