# Ejercicio 17 - Viajes y Turismo

## Descripción

En este ejercicio se crea una pequeña API REST utilizando Node.js y Express para practicar el uso de rutas GET.

La temática utilizada es viajes y turismo. La API permite consultar una lista de destinos turísticos y obtener un destino específico mediante su ID.

El objetivo principal es comprender cómo funcionan las rutas GET y cómo Express recibe una petición y devuelve una respuesta.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* npm
