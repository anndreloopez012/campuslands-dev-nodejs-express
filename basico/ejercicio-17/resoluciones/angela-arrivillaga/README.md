# Basico 17 - rutas GET

Tematica: viajes y turismo

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

El servidor corre en http://localhost:3000

## Probar

```bash
curl http://localhost:3000/basico/ejercicio-17
curl http://localhost:3000/basico/ejercicio-17/destinos
curl http://localhost:3000/basico/ejercicio-17/destinos/populares
curl http://localhost:3000/basico/ejercicio-17/destinos/2
curl http://localhost:3000/basico/ejercicio-17/destinos/99
curl http://localhost:3000/basico/ejercicio-17/paises
```
