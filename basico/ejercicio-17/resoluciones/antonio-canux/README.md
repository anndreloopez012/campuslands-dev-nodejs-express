# Ejercicio 17 - Rutas GET (Viajes y Turismo)

**Alumno:** Antonio Canux  
**Tema:** Rutas GET en Express  
**Temática:** Viajes y Turismo  
**Ruta:** `/basico/ejercicio-17`

## Ejecución
```bash
npm install
npm run dev
```

## Endpoints
- `GET /basico/ejercicio-17` - Estado del ejercicio.
- `GET /basico/ejercicio-17/destinos` - Listar todos los destinos.
- `GET /basico/ejercicio-17/destinos/top` - Destinos más populares.
- `GET /basico/ejercicio-17/destinos/:id` - Buscar destino por ID.
