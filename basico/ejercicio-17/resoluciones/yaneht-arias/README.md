# Ejercicio 17 - rutas GET

Solución sencilla con Node.js y JavaScript, sin Express ni dependencias externas.

## Comandos

Desde la raíz del repositorio, usa cualquiera de estos comandos:

- `cd basico/ejercicio-17/resoluciones/yaneht-arias && npm start`
- `cd basico/ejercicio-17/resoluciones/yaneht-arias && node src/app.js /salud`
