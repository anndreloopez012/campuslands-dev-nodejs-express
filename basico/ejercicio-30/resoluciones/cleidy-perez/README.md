# Ejercicio 30 - proyecto integrador basico

Solución sin dependencias externas para practicar **proyecto integrador basico** en el contexto de motos y mecanica.

## Ejecutar

```bash
cd basico/ejercicio-30/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
