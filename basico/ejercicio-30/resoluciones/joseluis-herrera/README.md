# Ejercicio 30 — API de motos y mecánica

## Descripción

API REST básica desarrollada con **Node.js y Express** para gestionar información de motos.

Este proyecto integra varios conceptos aprendidos durante los ejercicios anteriores:

* Rutas HTTP
* CRUD
* `req.params`
* `req.body`
* Validación
* Códigos de estado HTTP
* Express
* Servicios
* Datos en memoria
* Documentación técnica

---

## Tecnologías

* Node.js
* Express
* JavaScript
* HTTP
* JSON
