# Ejercicio 05 - fs para leer archivos

Solución sin dependencias externas para practicar **fs para leer archivos** en el contexto de futbol y futbol sala.

## Ejecutar

```bash
cd basico/ejercicio-05/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
