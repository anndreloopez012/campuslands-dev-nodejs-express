# Ejercicio 05 - fs para leer archivos

Practica de lectura de archivos usando `fs` y solo Node.JS.

## Uso

Ubicarse en:
```bash
basico/ejercicio-05/resoluciones/jakelin-quino/
```

El programa lee `data/teams.json` con `node:fs/promises`, convierte el contenido desde JSON y muestra un resumen de equipos de futbol y futbol sala. Probar:
```bash
npm start
```
Resultado:
```bash
Equipos encontrados: 3
Halcones - futbol - Bogota
Rayo Sala - futbol sala - Cali
Titanes - futbol - Medellin
```
