# Ejercicio 05 - Lectura de archivos JSON

Ejercicio de Node.js para practicar la lectura y procesamiento de archivos JSON utilizando módulos nativos.

## Estructura

```text
├── data/
│   └── equipos.json
├── src/
│   └── app.js
└── package.json
```

## Ejecución

```bash
npm install
npm start
```

El programa lee `equipos.json`, convierte la información a objetos JavaScript y muestra los equipos encontrados en la consola.
