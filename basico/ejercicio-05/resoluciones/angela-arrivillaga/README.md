# Basico 05 - fs para leer archivos

Tematica: futbol y futbol sala

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

El servidor corre en http://localhost:3000

## Probar

```bash
curl http://localhost:3000/basico/ejercicio-05
curl http://localhost:3000/basico/ejercicio-05/archivo
curl http://localhost:3000/basico/ejercicio-05/jugadores
curl http://localhost:3000/basico/ejercicio-05/jugadores/Messi
curl http://localhost:3000/basico/ejercicio-05/jugadores/Pele
```
