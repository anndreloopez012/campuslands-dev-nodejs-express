# Ejercicio 14 - validacion de entrada

Solución sin dependencias externas para practicar **validacion de entrada** en el contexto de libros.

## Ejecutar

```bash
cd basico/ejercicio-14/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
