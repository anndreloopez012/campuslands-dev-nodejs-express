# Ejercicio 25 - Respuestas HTTP correctas

## Temática

Videojuegos RPG.

## Objetivo

Crear una API REST sencilla con Node.js y Express para practicar el uso correcto de los códigos de estado HTTP.

El ejercicio trabaja principalmente con:

* `200 OK`
* `201 Created`
* `400 Bad Request`
* `404 Not Found`

Los datos se almacenan temporalmente en memoria.

---

## Tecnologías

* Node.js
* Express
* JavaScript
* JSON
* API REST
