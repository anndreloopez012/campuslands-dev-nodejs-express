# Ejercicio 16 - primer servidor Express

Solución sin dependencias externas para practicar **primer servidor Express** en el contexto de ropa y sneakers.

## Ejecutar

```bash
cd basico/ejercicio-16/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
