## Ejecución
```bash

```

## Endpoints
- `GET /basico/ejercicio-16` - Estado del ejercicio.
- `GET /basico/ejercicio-16/sneakers` - Lista de sneakers disponibles.
- `GET /basico/ejercicio-16/info` - Información de la tienda.
