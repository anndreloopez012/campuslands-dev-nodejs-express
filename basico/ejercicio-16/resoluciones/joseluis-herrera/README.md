# Ejercicio 16 - Primer Servidor Express

## Temática

Ropa y sneakers.

## Objetivo

Crear el primer servidor utilizando **Node.js** y **Express**.

El ejercicio busca comprender los conceptos básicos de un servidor Express, como la creación de la aplicación, definición de rutas, respuestas HTTP y ejecución del servidor.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* HTTP
* JSON
