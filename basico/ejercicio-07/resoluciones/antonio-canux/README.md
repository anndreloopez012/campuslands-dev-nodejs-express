# Resolución - Ejercicio 07: process.argv y CLI

Esta entrega contiene una solución híbrida para la gestión de autos de lujo. Implementa una API con Express y una herramienta de línea de comandos (CLI) que comparten la misma lógica de negocio, demostrando el uso avanzado de `process.argv`.

## 🛠️ Cómo instalar

1. Clona el repositorio y navega a esta carpeta.
2. Ejecuta `npm install` para instalar Express.
