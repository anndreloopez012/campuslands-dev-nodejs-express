# Autos de Lujo - CLI con Node.js

## Autor

Wilder Catú

## Descripción

Este proyecto es una pequeña solución backend desarrollada con Node.js
para practicar el uso de `process.argv` y la creación de una interfaz
de línea de comandos (CLI).

La temática utilizada es un catálogo de autos de lujo.

El objetivo no es crear una aplicación grande, sino comprender cómo
Node.js puede recibir información desde la terminal, procesarla,
validarla y ejecutar diferentes acciones.

---

## Objetivo del ejercicio

Practicar los siguientes conceptos:

- Node.js
- `process.argv`
- Argumentos de línea de comandos
- Funciones
- Validación básica
- Búsqueda de información
- Estructuras de datos con arrays y objetos
- Comandos CLI
- Manejo básico de errores
- `process.exitCode`
