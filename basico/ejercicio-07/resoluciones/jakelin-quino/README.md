# Ejercicio 07 - process.argv y aplicaciones CLI

Practica de argumentos de consola usando solo Node.JS.

## Uso

Ubicarse en:
```bash
basico/ejercicio-07/resoluciones/jakelin-quino/
```

El programa recibe el modelo, ano y precio de un auto de lujo. Probar:
```bash
npm start -- Phantom 2025 350000
```
Resultado:
```bash
Vehiculo: Phantom
Ano: 2025
Precio: $350.000
```

Para probar el error:
```bash
npm start -- Phantom 2025 0
```
