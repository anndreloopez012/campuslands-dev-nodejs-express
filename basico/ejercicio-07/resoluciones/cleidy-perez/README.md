# Ejercicio 07 - process.argv y CLI

Solución sin dependencias externas para practicar **process.argv y CLI** en el contexto de autos de lujo.

## Ejecutar

```bash
cd basico/ejercicio-07/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
