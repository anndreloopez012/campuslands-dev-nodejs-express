# Ejercicio 27 — Logs simples

## Temática

MOBA esports.

## Objetivo

Crear una API sencilla con Node.js y Express que permita consultar equipos de esports y registrar logs básicos de las peticiones recibidas.

El ejercicio introduce el concepto de **middleware** utilizando un logger sencillo.

---

## Tecnologías

* Node.js
* Express
* JavaScript
* HTTP
* Middleware
