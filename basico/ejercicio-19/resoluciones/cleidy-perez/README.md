# Ejercicio 19 - req.params y req.query

Solución sin dependencias externas para practicar **req.params y req.query** en el contexto de tatuajes.

## Ejecutar

```bash
cd basico/ejercicio-19/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
