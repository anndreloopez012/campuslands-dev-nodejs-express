# Ejercicio 19 - Tatuajes

## Descripción

En este ejercicio se crea una pequeña API REST utilizando Node.js y Express para practicar dos formas de recibir información desde una URL:

* `req.params`
* `req.query`

La temática utilizada es tatuajes.

La API permite consultar tatuajes por ID y buscar tatuajes utilizando su estilo.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* npm
* Postman
