# Ejercicio 19 - req.params y req.query (Tatuajes)

**Alumno:** Antonio Canux  
**Tema:** Manejo de req.params y req.query  
**Temática:** Estudio de Tatuajes  
**Ruta:** `/basico/ejercicio-19`

## Ejecución
```bash
npm install
npm run dev
```

## Endpoints
- `GET /basico/ejercicio-19` - Estado del ejercicio.
- `GET /basico/ejercicio-19/tattoos` - Listar tatuajes con filtros `?style=` y `?artist=`.
- `GET /basico/ejercicio-19/tattoos/:id` - Buscar tatuaje por parámetro `:id`.
