# Ejercicio 02 - npm scripts y package.json

Solución sin dependencias externas para practicar **npm scripts y package.json** en el contexto de shooters competitivos.

## Ejecutar

```bash
cd basico/ejercicio-02/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
