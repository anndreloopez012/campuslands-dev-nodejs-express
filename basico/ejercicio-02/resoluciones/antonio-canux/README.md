# Básico 02 - npm scripts y package.json 🎯

API REST básica estructurada en capas, enfocada en demostrar el uso correcto y creación de scripts personalizados en el `package.json`, con temática de shooters competitivos.

## ⚙️ Scripts disponibles

Este proyecto utiliza los siguientes comandos (definidos en `package.json`):

- `npm install`: Instala las dependencias necesarias.
- `npm run dev`: Levanta el servidor en modo desarrollo (recarga automática).
- `npm start`: Levanta el servidor en modo producción.
- `npm run matchmaking`: Imprime un mensaje en consola simulando la búsqueda de partida.
- `npm run ping`: Simula un test de latencia al servidor.

## 🚀 Cómo ejecutar

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar en modo desarrollo
npm run dev
