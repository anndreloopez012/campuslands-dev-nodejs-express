# Ejercicio 02 - npm scripts y package.json

Solución sencilla con Node.js y JavaScript, sin Express ni dependencias externas.

## Comandos

Desde la raíz del repositorio, usa cualquiera de estos comandos:

- `cd basico/ejercicio-02/resoluciones/yaneht-arias && npm start`
- `cd basico/ejercicio-02/resoluciones/yaneht-arias && npm run dev`
- `cd basico/ejercicio-02/resoluciones/yaneht-arias && npm run info`
