# Ejercicio 02

## Descripción

En este ejercicio se creó un pequeño programa utilizando **Node.js** que permite generar **contraseñas aleatorias** desde la terminal.
El programa utiliza diferentes opciones seleccionadas por el usuario para crear una contraseña personalizada.
Para realizar el ejercicio se utilizaron las dependencias **Inquirer** y **Chalk**.

## Archivos principales

| ----------------------------- | ------------------------------------------------------------------------------ |
| `src/generador_contraseña.js` | Contiene el código JavaScript encargado de generar la contraseña.              |
| `package.json`                | Contiene la información del proyecto, dependencias y comandos para ejecutarlo. |
| `package-lock.json`           | Guarda las versiones exactas de las dependencias instaladas.                   |
| `README.md`                   | Contiene la documentación del ejercicio.                                       |

---

## Dependencias utilizadas

### Inquirer
permite realizar preguntas al usuario directamente desde la terminal.

### Chalk
permite agregar colores y estilos al texto mostrado en la terminal.
En este proyecto se utiliza para mostrar la contraseña de una manera más visual.

---

# Cómo ejecutar el proyecto

## 1. Entrar a la carpeta del ejercicio
Desde la raíz del repositorio ejecuta:

```bash
cd basico/ejercicio-02/resoluciones/joseluis-herrera
```
---
## 2. Instalar las dependencias
```bash
npm install
```
---
## 3. Ejecutar el programa
```bash
npm run start
```
