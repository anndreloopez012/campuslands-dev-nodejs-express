# Ejercicio 26 - Códigos de estado HTTP

## Temática

Shooters competitivos.

## Objetivo

Crear una API REST sencilla con Node.js y Express para practicar el uso correcto de diferentes códigos de estado HTTP.

El ejercicio utiliza jugadores de shooters competitivos almacenados temporalmente en memoria.

---

## Tecnologías

* Node.js
* Express
* JavaScript
* JSON
* API REST
