# Ejercicio 03 - modulos CommonJS

Practica de modulos CommonJS usando solo Node.JS.

## Uso

Ubicarse en:
```bash
basico/ejercicio-03/resoluciones/jakelin-quino/
```

La informacion y la funcion del equipo estan en `src/team.js` y se importan desde `src/index.js` con `require`. Probar:
```bash
npm start
```
Resultado:
```bash
Guardianes del Nexus juega MOBA Legends con 5 integrantes.
Jugadores: Luna, Rex, Mina, Kai, Orion
```
