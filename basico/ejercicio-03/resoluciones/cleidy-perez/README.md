# Ejercicio 03 - modulos CommonJS

Solución sin dependencias externas para practicar **modulos CommonJS** en el contexto de MOBA esports.

## Ejecutar

```bash
cd basico/ejercicio-03/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
