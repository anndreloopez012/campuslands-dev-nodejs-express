
# Ejercicio 03: Módulos CommonJS

Solución backend en Node.js y Express usando módulos CommonJS (`require`/`module.exports`) para un escenario de MOBA esports.

## 🚀 Ejecución
1. `npm install`
2. `npm run dev`

## 📡 Endpoints
- **GET** `/basico/ejercicio-03/health`
- **GET** `/basico/ejercicio-03/heroes`
- **POST** `/basico/ejercicio-03/heroes`
