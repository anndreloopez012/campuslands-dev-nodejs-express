# Basico 03 - modulos CommonJS

Tematica: MOBA esports

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

El servidor corre en http://localhost:3000

## Probar

```bash
curl http://localhost:3000/basico/ejercicio-03
curl http://localhost:3000/basico/ejercicio-03/campeones
curl http://localhost:3000/basico/ejercicio-03/campeones/2
curl http://localhost:3000/basico/ejercicio-03/campeones/50
curl "http://localhost:3000/basico/ejercicio-03/kda?kills=10&deaths=2&assists=5"
```
