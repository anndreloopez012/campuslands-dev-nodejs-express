# Ejercicio 20 - middleware express.json

Solución sin dependencias externas para practicar **middleware express.json** en el contexto de dibujo digital.

## Ejecutar

```bash
cd basico/ejercicio-20/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
