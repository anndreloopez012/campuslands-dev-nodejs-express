# Ejercicio 20 - Dibujo Digital

## Descripción

En este ejercicio se crea una pequeña API REST utilizando Node.js y Express para aprender el funcionamiento del middleware `express.json()`.

La temática utilizada es dibujo digital.

La API permite consultar dibujos registrados y crear nuevos dibujos enviando información en formato JSON.

El objetivo principal es comprender cómo Express recibe y procesa un cuerpo JSON mediante `req.body`.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* npm
* Postman
