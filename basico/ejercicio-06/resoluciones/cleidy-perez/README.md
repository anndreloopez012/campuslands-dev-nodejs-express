# Ejercicio 06 - path y rutas seguras

Solución sin dependencias externas para practicar **path y rutas seguras** en el contexto de motos y mecanica.

## Ejecutar

```bash
cd basico/ejercicio-06/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
