# Basico 01 - Node runtime y consola

Tematica: videojuegos RPG

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

El servidor corre en http://localhost:3000

## Probar

```bash
curl http://localhost:3000/basico/ejercicio-01
curl http://localhost:3000/basico/ejercicio-01/runtime
curl "http://localhost:3000/basico/ejercicio-01/heroe?nombre=Arthas"
curl http://localhost:3000/basico/ejercicio-01/heroe
```
