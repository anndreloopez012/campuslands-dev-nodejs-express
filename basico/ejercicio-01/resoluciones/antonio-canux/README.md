# Básico 01 - Node Runtime y Consola

**Camper:** Antonio Canux

Solución al primer ejercicio básico de Node.js en Campuslands, aplicando arquitectura de capas para un entorno de videojuegos RPG.

## Cómo ejecutar el proyecto

1. Asegúrate de tener Node.js v20 o superior.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Levanta el servidor en modo desarrollo:
   ```bash
   npm run dev
   ```
