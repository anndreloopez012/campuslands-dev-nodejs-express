# Ejercicio 21 - Animación 3D

## Descripción

En este ejercicio se crea una pequeña API REST utilizando Node.js y Express para aprender una estructura básica utilizando:

* `src`
* `routes`
* `controllers`

La temática utilizada es animación 3D.

El objetivo es separar las rutas de la lógica de las peticiones para conseguir una estructura más ordenada.

## Tecnologías utilizadas

* Node.js
* Express
* JavaScript
* npm
* Postman
