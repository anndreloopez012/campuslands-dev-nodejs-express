# Ejercicio 21 - estructura src routes controllers

Solución sin dependencias externas para practicar **estructura src routes controllers** en el contexto de animacion 3D.

## Ejecutar

```bash
cd basico/ejercicio-21/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
