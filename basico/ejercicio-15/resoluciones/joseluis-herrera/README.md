# Ejercicio 15 - Mini API HTTP Nativa

## Temática

Comida urbana.

## Objetivo

Crear una pequeña API HTTP utilizando **Node.js** y su módulo nativo `http`.

El objetivo principal es comprender cómo funciona una API HTTP básica sin utilizar frameworks como Express.

La API permite consultar una lista de comidas urbanas y también demuestra cómo manejar una ruta que no existe.

## Tecnologías utilizadas

* Node.js
* JavaScript
* Módulo nativo `http`
* HTTP
* JSON
