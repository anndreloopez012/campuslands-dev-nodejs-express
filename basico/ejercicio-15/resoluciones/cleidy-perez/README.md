# Ejercicio 15 - mini API HTTP nativa

Solución sin dependencias externas para practicar **mini API HTTP nativa** en el contexto de comida urbana.

## Ejecutar

```bash
cd basico/ejercicio-15/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
