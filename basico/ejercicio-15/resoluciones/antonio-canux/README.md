# Ejercicio 15 - Mini API HTTP Nativa (Comida Urbana)

**Alumno:** Antonio Canux  
**Tema:** Mini API con módulo nativo http de Node.js  
**Temática:** Comida Urbana  
**Ruta:** `/basico/ejercicio-15`

## Ejecución
```bash
npm run dev
```

## Endpoints
- `GET /basico/ejercicio-15` - Estado del ejercicio.
- `GET /basico/ejercicio-15/foods` - Listar puestos de comida urbana.
- `POST /basico/ejercicio-15/foods` - Registrar platillo urbano.
