# Ejercicio 24 - CRUD basico

Solución sin dependencias externas para practicar **CRUD basico** en el contexto de formulas quimicas.

## Ejecutar

```bash
cd basico/ejercicio-24/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
