# Ejercicio 24 - CRUD básico de fórmulas químicas

## Temática

Fórmulas químicas.

## Objetivo

Crear una API REST sencilla con Node.js y Express para practicar las operaciones básicas de un CRUD:

* Create
* Read
* Update
* Delete

Los datos se almacenan temporalmente en memoria mediante un array de JavaScript.

---

## Tecnologías

* Node.js
* Express
* JavaScript
* JSON
* API REST
